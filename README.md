# New Map AI Visibility (Claude plugin)

Ask Claude which AI engines recommend a brand, who they name instead, and why.

- **Free audit, no key:** `audit` runs New Map's free AI visibility audit for any website (a sample of buyer questions on several engines, the rival named instead, the first fixes, a link to the full report). One per domain per 30 days.
- **Live data for New Map clients:** with a client key, the read tools return the weekly measurement (100 or 300 questions on seven engines), trends, verbatim answers, competitors and citations, scoped to the client's workspace.

Read-only. Nothing in this plugin writes to New Map. See SETUP.md.

New Map (thenewmap.ai) measures how ChatGPT, Perplexity, Gemini, Google AI, Claude and Grok answer about a brand, fixes what the engines get wrong on the brand's site, and places the brand where the engines look. Operated by Brinchmann Consulting UG, Berlin.
